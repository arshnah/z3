## Android is here

Zeta now runs independently on Android, with a native player and a signed APK.

- Background playback and Android system media controls, with automatic track advance.
- YouTube Music and JioSaavn search, playback, and downloads.
- Offline library, playlists, favourites, lyrics, and listening statistics.
- Import audio through Android's file picker and share songs or downloaded audio through the native share sheet.
- Optional haptic feedback and keep-screen-awake settings.
- Phone layouts checked in portrait, landscape, and compact sizes; lighter visualizers on Android.

## Last.fm and ListenBrainz

Both desktop and Android now support now-playing updates and scrobbling. Connect accounts in **Settings → Scrobbling**. Last.fm uses browser authorization; ListenBrainz uses your personal user token.

Listens count actual playback, excluding pauses and seek jumps. Offline and failed scrobbles queue locally and retry independently for each connected service.

## Downloads

The desktop package formats and filename patterns match v0.4.0, updated to 0.4.1: Windows installer, portable EXE and MSI; Linux AppImage and DEB; macOS DMG and ZIP for Apple Silicon and Intel, with updater metadata and blockmaps.

**Android:** install `Zeta-0.4.1-android.apk` (Android 7.0 or newer). This is the first signed Android release. If you installed the earlier local debug APK, uninstall that debug app before installing the release APK; Android requires matching signing keys for an in-place update. Uninstalling removes that app's private library.

## Validation

Storage and scrobbling tests, desktop builds, Android build/lint, and 45 reviewed Android emulator screenshots covering the main screens, native sheets, offline/background playback, landscape, and compact layouts. Personal account authorization is required to send live scrobbles.
